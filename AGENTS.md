# Project instructions
Use Chinese for beginner-facing explanations. This is an unofficial local learning tool.
Keep task_bank as original starter material; tasks is generated learner work and is ignored by Git.
Never add keys, .qwen, practice-state.json, personal chats, node_modules, or absolute personal paths to commits.
Do not broaden Qwen approval mode beyond auto-edit or claim QWEN.md creates an OS sandbox.
For infrastructure edits, run python -m unittest discover -s tests -v and syntax-check the inline UI script.
When adding tasks, align README, fixture data, starter files and checks; author QA must use separate copies so learner files remain unanswered.
