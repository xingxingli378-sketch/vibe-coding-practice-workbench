# 实训成绩汇总（自编训练题）
实现 summary.py 中 summarize(results) -> dict。
输入列表必须刚好三条，每条是包含 task 和 score 的字典。
task 必须是整数 1、2、3，各出现一次；score 必须是 0 到 100 之间的有限整数或浮点数；两者均不接受布尔值，score 不接受字符串。
无效输入抛出 ValueError，不修改输入。
输出 total（总分，四舍五入到两位）、average（平均分，四舍五入到两位）、level（平均分 >=85 为“优秀”，>=60 为“通过”，否则“不通过”）。等级按未舍入平均分判断。
注意：这里的等级阈值是自编练习标准，与学校的优秀标准无关。
不可修改任务说明或检查程序。点击运行检查验证。
